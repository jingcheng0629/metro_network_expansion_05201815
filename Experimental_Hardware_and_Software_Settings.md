## 3. FCM-PPO Network Architecture

| Module | Architecture or setting |
|---|---|
| Spatial CNN | Six-channel input; convolutional channel numbers of 32, 64, and 128; `3 x 3` kernels; stride=2; padding=1; batch normalization and ReLU |
| Residual module | One residual block at each convolutional stage |
| Self-attention | One self-attention module after the final 128-channel convolutional stage; the residual scaling parameter is initialized to 0 |
| Candidate LSTM | Input dimension 5; hidden dimension 256 |
| Feature-coupling layer | Fully connected dimensions 512 -> 256; ReLU activation |
| Actor | 256-dimensional projection with a scalar logit output for each candidate station |
| Critic | Fully connected dimensions 256 -> 128 -> 1; ReLU activation |

The state consists of a six-channel global spatial tensor and candidate-station features. The six spatial channels represent POI, housing prices, the existing metro network, the current agent position, the historical trajectory, and a restricted-area mask. Candidate-station features are five-dimensional local features.

## 6. Objective Weights and Experimental Design

The total reward is the weighted sum of the travel-demand and social-equity rewards:

```text
R_total = w_td * R_td + w_eq * R_eq
```

The repeated experiments use four preference-weight configurations:

| Weight configuration | Travel-demand weight `w_td` | Social-equity weight `w_eq` | Interpretation in the paper |
|---|---:|---:|---|
| W80E20 | 0.8 | 0.2 | Travel-demand priority |
| W70E30 | 0.7 | 0.3 | Relatively higher travel-demand priority |
| W60E40 | 0.6 | 0.4 | Balanced demand and equity |
| W50E50 | 0.5 | 0.5 | Complete balance |

The full set of repeated experiments covers three budget levels (90, 120, and 150), two expansion lines (`Line_E1` and `Line_NE1`), four weight configurations, and six random seeds.

## 7. Comparison Algorithm Settings

| Algorithm | Setting |
|---|---|
| FCM-PPO / PPO | Uses the spatial encoder, candidate-sequence module, feature-coupling layer, and feasibility-based action mask described above |
| DQN | Discrete-action reinforcement-learning comparison baseline |
| DDPG | The actor outputs a five-dimensional continuous weight vector, which is then mapped to discrete candidate stations; exploration noise decays from 0.2 to 0.01; the soft-update coefficient is `tau=0.001` |
| GA | Population size 100; 500 evolutionary generations; mutation probability 0.2; elite retention |
| MP | Integer programming solved with Gurobi; the candidate subgraph is generated by breadth-first search, with a maximum of 1,000 nodes |

## 8. Network-Resilience Evaluation Parameters

Network resilience is evaluated independently after route generation and is not included as a reward offset during training. The fixed parameters are as follows:

| Parameter | Setting |
|---|---|
| Attack strategy | Degree-based attack, prioritizing the highest-degree nodes |
| Number of attacked nodes | 3 |
| Capacity tolerance coefficient `alpha` | 0.3 |
| Load redistribution | Proportional to the initial load |
| TEL weight `mu` | 0.5 |

Transportation Efficiency Loss is defined as:

```text
TEL = mu * (1 - K_a / K_o) + (1 - mu) * (1 - E_a / E_o)
```

A lower TEL indicates a smaller loss of transportation efficiency after an attack, lower network vulnerability, and greater resilience.
